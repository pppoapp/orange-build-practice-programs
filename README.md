# 여러 사업 실적 통합 — 멀티에이전트 기초 실습

이 폴더를 Codex 또는 Claude Code에서 여세요. 선택한 과제인 여러 사업 실적 통합의 자료만 들어 있습니다. data/programs/RULES.md의 기준과 자료를 먼저 확인한 다음 워크북의 요청문을 복사해서 제작을 시작합니다.

모두 교육용 가상 자료입니다. 정상 자료와 오류·경계 사례 파일은 따로 실행하세요. 기준 정리·자료 계산·화면 만들기·결과 확인을 실제로 따로 일하는 에이전트에게 맡깁니다.

결과물은 내 컴퓨터에서 index.html을 열어 사용하는 대시보드입니다. 요약 수치, 파이·막대·꺾은선 차트, 필터, 상세 표와 CSV 다운로드를 함께 만듭니다. 샘플 자료는 로컬 실행 시 기본으로 보이도록 코드에 포함하거나 브라우저 파일 선택으로 읽으세요. file://에서 fetch로 CSV를 자동 읽는 방식에 의존하지 마세요. 완성 프로그램은 ZIP에 포함되어 있지 않습니다.

## 준비된 팀 설정

Codex는 Sol+Luna, Claude Code는 Opus+Sonnet 팀으로 만듭니다. TEAM.md와 .codex/agents/ 또는 .claude/agents/에 준비된 역할 설정을 사용합니다. 숨김 폴더를 직접 편집할 필요는 없습니다. 워크북 4단계의 요청을 복사해 설정과 담당 파일을 확인하고 5단계에서 제작합니다. 모델 선택은 앱에서 진행하며, 설정을 읽지 못하면 폴더를 다시 엽니다.
