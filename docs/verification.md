# 제작 및 검증 기록

## 역할과 담당 파일

| 역할 | 생성 요청 모델 / 추론 수준 | 담당 |
| --- | --- | --- |
| wb_criteria | gpt-6-luna / high | docs/criteria.md |
| wb_calculator | gpt-6-luna / high | js/calculator.js, js/sample-data.js, tests/calculator.test.cjs |
| wb_ui | gpt-6-luna / high | index.html, css/styles.css, js/ui.js |
| wb_reviewer | gpt-6.1-sol / medium | 원본 및 결과 읽기 전용 검증, 수정안 전달 |

네 담당은 실제 별도 에이전트로 생성했습니다. 모두 fork_turns="none"으로 필요한 역할과 자료 경로만 전달했습니다. 역할 TOML을 읽도록 지정하고 업무·담당 파일·제약을 명시했습니다. 추가 위임은 금지했습니다. 기준 정리를 먼저 공유하고 계산과 화면을 병행한 뒤 독립 검증했습니다.

도구에는 실제 해석된 모델/추론 수준 메타데이터가 노출되지 않았습니다. 위 표는 생성 요청 설정의 기록이며 실제 모델을 추가로 인증한 기록은 아닙니다. 현재 조율 대화의 모델도 확인 가능한 실행 메타데이터가 없습니다.

## 계산 검증

- Node 계산 테스트 9개 통과: 원본 샘플 일치, 정상 합계, 오류 처리, 숫자 사유 구분, 헤더 오류, CSV 인용·개행, 빈 필터·0명, CSV 왕복, 고정 분야 색상.
- 독립 검증 담당이 제작 테스트에 의존하지 않고 원본에서 기대값을 재계산했습니다.
- 정상: 18행, 참여 1,410명, 수료 1,171명, 83.04964539007092%, 사업 6개, 연도 3개, 기본 주의 1행.
- 연도별: 2024년 400/320=80%, 2025년 470/388≈82.553%, 2026년 540/463≈85.741%.
- 분야별 참여: 교육 510명, 일자리 525명, 지역사회 375명.
- 오류: 유효 2행, 제외 3행, 참여 20명, 수료 15명, 75%. 0명 행은 유지하며 수료율·판정은 계산 불가.
- 모든 연도 선택 부분집합 8종과 주의 기준 70/80에서 요약·차트·표·CSV의 동일 자료 적용 확인. 기준 80에서는 주의 8행이고 정확히 80%인 행은 주의가 아닙니다.

## 통합 코드 검증

`tests/ui.integration.cjs`의 가벼운 DOM 대체 환경에서 실제 UI 스크립트와 이벤트를 실행했습니다. 기본 요약·SVG 3개 생성·18행, 2024년 필터, 빈 선택, CSV 다운로드·재입력, 주의 기준 변경, 오류 CSV 업로드·제외 이유, 기본 자료 복원이 통과했습니다. JS 문법 검사도 통과했습니다.

독립 확인에서는 파일 읽기 실패·잘못된 헤더 이후 기존 자료 유지, 헤더만 있는 빈 CSV, 0명 전용 CSV, HTML 태그를 포함한 사업명의 textContent 처리도 확인했습니다.

## 실제 화면 확인의 제한

Windows Computer Use는 현재 브라우저 URL을 충분히 확신할 수 없어 이번 턴을 중단했습니다. 이후 브라우저 자동화를 재시도하지 않았습니다. 따라서 실제 브라우저에서 파일 열기, 차트·표 표시 및 모바일 배치의 시각 확인은 미완료입니다. DOM 대체 환경의 검사는 실제 브라우저 레이아웃 확인을 대신하지 않습니다.

직접 실행은 프로젝트의 index.html을 Chrome 또는 Edge에서 열면 됩니다. 자세한 순서는 docs/usage.md를 참고하세요. 원본 자료와 프로젝트·전역 설정은 변경하지 않았고, 커밋·저장소 생성·푸시·외부 배포는 하지 않았습니다.

## 기존 wb_reviewer의 독립 재검증

사용자의 후속 검증 요청에 따라 같은 wb_reviewer가 기존 작업을 이어갔습니다. 새 팀을 만들지 않았고 대시보드 코드와 원본 자료는 수정하지 않았습니다.

원본에서 직접 기대값을 계산한 뒤, DOM 대체 환경에서 실제 연도 change 이벤트, CSV 업로드 이벤트, 다운로드 이벤트를 실행해 생성된 화면 요소와 CSV Blob 내용을 비교했습니다. 제작 테스트의 기대값만 재사용하지 않았습니다.

전체 선택·단일 연도·연도 쌍·전체 해제 등 8개 연도 선택 조합에서 요약, 표 각 셀, 파이 범례, 막대 수치, 꺾은선 수치, 다운로드 CSV가 같은 유효 행을 사용했습니다. CSV의 한글 7열과 순서 및 재입력도 일치했습니다. 정상과 오류 자료는 각각 따로 검증했습니다.

기대값과 다른 계산·표시 결과는 발견되지 않아 대시보드 코드는 변경하지 않았습니다. 이 후속 검증에서 실제 in-app browser 접근은 file:// 프로토콜이 허용되지 않는다는 보안 정책으로 차단되었습니다. 다른 경로로 우회하지 않았으며, 실제 브라우저 클릭 및 파일 저장 확인은 미실행입니다. SVG 요소/다운로드 Blob 내용 확인은 DOM 대체 환경의 실행 결과입니다.
